## Implementation Plan

### Step 1: Create pre-aggregated fill rate view (fixes 6 questions)

Create `SUPPLYCHAIN_DB.CORE.V_ORDER_FULFILLMENT` — a Snowflake VIEW that pre-aggregates shipped quantities to the order level:

```sql
CREATE OR REPLACE VIEW SUPPLYCHAIN_DB.CORE.V_ORDER_FULFILLMENT AS
SELECT
    fo.ORDER_ID, fo.PART_ID, fo.PLANT_ID, fo.CUSTOMER_ID,
    fo.ORDER_DATE, fo.REQUESTED_DELIVERY_DATE, fo.PRIORITY, fo.STATUS,
    fo.ORDERED_QUANTITY,
    COALESCE(spo.TOTAL_SHIPPED, 0) AS SHIPPED_QUANTITY
FROM SUPPLYCHAIN_DB.CORE.FACT_ORDER fo
LEFT JOIN (
    SELECT ORDER_ID, SUM(SHIPPED_QUANTITY) AS TOTAL_SHIPPED
    FROM SUPPLYCHAIN_DB.CORE.FACT_SHIPMENT
    WHERE IS_VALID_SHIPMENT = TRUE
    GROUP BY ORDER_ID
) spo ON fo.ORDER_ID = spo.ORDER_ID;
```

This view has **83 rows at order grain**. Fill rate = `SUM(SHIPPED_QUANTITY) / NULLIF(SUM(ORDERED_QUANTITY), 0)` is now safe at any GROUP BY.
